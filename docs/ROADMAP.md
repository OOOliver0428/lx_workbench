## 0.5.1

### 新功能引导系统（What's New / 功能导览）

每次较大功能更新后，用户首次打开系统时看到引导。需求要点与已对齐的设计决策：

- **一套引擎、两种步骤形态**：`modal`（居中公告弹窗，做更新总览）与 `spotlight`（页面玻璃模糊不可点击 + 气泡锚定在功能元素旁），编排时自由组合。
- **多步骤导览**：支持「下一个 / 跳过」，最后一步「好的」结束。
- **编排方式**：代码内 TS 配置文件（`frontend/app/feature-guides.ts`），每次发版新增一条带新 `id` 的 guide；锚点用 `data-tour` 属性（导航项先行埋点，如 `nav-records`）。
- **已读判定**：localStorage `featureGuide.seen:{userId}`，与主题、更新日志红点机制一致，无后端改动。
- **容错**：锚点元素不存在（如权限不可见）自动跳过该步；全部缺失则静默标记已读。
- 首个编排内容拟定为 0.5.1 更新总览 + 工作记录 Alt+W 快捷键引导（公告步 + 焦点步各一）。
- 实现影响面：纯前端（配置模块 + 运行时组件挂 `workspace-app.tsx` + globals.css 样式 + 单测），新增样式遵守主题变量纪律（禁 hex 字面量）。
