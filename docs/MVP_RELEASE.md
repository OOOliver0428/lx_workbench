# MVP 阶段说明

## 当前目标

先跑通以项目为主线的协作闭环，使工作记录和周报能够准确归属到统一项目，并为后续团队
领导者的作战台展示提供可靠数据。

## 已纳入

- 本地账号、首次改密、会话超时、角色与直属 Leader。
- 系统预置头像及全角色个人设置。
- 项目标签、父子层级、负责人、成员、别名、查重、状态流转和合并。
- 项目任务、负责人、协作者、优先级及状态流转。
- 工作记录、半小时工时档位、项目/任务关联、待归集及产出物。
- DeepSeek、GLM、Kimi、MiniMax 的管理员配置、连接测试和密钥加密存储。
- AI 对话与基于当周有效工作记录生成、编辑和提交周报。
- 审计日志、乐观锁、SQLite WAL、Alembic 迁移和一致性备份。

## 本阶段暂缓

- 作战台首页、图表和领导决策大屏。
- 本地文档上传后由 AI 自动拆分并写入项目、任务和工作记录。
- HTTPS、统一身份认证、多实例高可用和外部对象存储。

## 试运行部署边界

- 仅部署在受控公司内网，使用 IP 与端口访问。
- 前后端固定为单个应用实例；SQLite 数据库必须位于服务器本机磁盘。
- 防火墙只允许试点网段或明确设备访问。
- `.env`、数据库、备份和大模型密钥不进入 Git。
- 正式推广前必须启用 HTTPS，并将安全 Cookie 配置切换为生产值。

## 提交前检查

```powershell
uv run ruff check app tests
uv run pytest

Set-Location frontend
npm run lint
npm test
```

同时确认 Alembic 处于最新版本、示例配置不含真实密钥，且 Git 变更中不存在数据库、日志、
缓存、原始设计素材或旧原型文件。
