# 全量功能测试数据

执行以下命令会在当前配置的数据库中创建一套独立演示数据：

```powershell
uv run python -m app.cli seed-demo-data --password "Demo-Password-2026!"
```

命令会先升级数据库，并使用确定性 ID 新建或刷新演示数据。重复执行不会重复堆积记录，也不会
修改非演示账号和业务数据。`production` 环境默认拒绝执行。

## 测试账号

| 登录名 | 显示名称 | 主要用途 |
| --- | --- | --- |
| `demo_root` | 演示·系统维护账号 | 全权限、全部工作记录、隐藏账号规则 |
| `demo_admin` | 演示·系统管理员 | 系统设置、下级权限配置 |
| `demo_leader` | 演示·团队负责人 | 三个作战台视图、团队周报、直属成员矩阵 |
| `demo_full` | 演示·方案顾问（全功能） | 项目、任务、个人记录、周报完整操作 |
| `demo_opportunity` | 演示·售前顾问（商机视图） | 仅商机追踪视图和只读项目任务 |
| `demo_personal` | 演示·交付顾问（个人工作） | 默认只读项目任务、个人记录和周报 |
| `demo_newcomer` | 演示·新成员（初始权限） | 新建账号默认权限场景 |
| `demo_inactive` | 演示·已停用成员 | 停用账号登录拦截 |

所有账号也可以使用表中的显示名称登录。密码由执行命令的 `--password` 参数决定。

## 覆盖范围

- 权限：系统维护账号、系统管理员、团队负责人、全功能成员、部分可见成员、无权限成员和停用账号。
- 作战台：独立商机追踪、工作管理、周期总览、五周趋势、提交矩阵、阶段推进时间线和团队总结。
- 商机：7 个历史项目迁移得到的关联商机，以及 1 个达到方案交流、尚未关联项目的商机，可完整验证“创建并关联项目”。
- 项目：待审批、进行中、暂停、完成、拒绝、归档、合并、父子层级、标签、成员和别名。
- 任务：待办、进行中、阻塞、完成、取消、协作者、改派历史和跨项目关联。
- 工作记录：当前周与历史周、项目/任务关联、未关联工作、风险、下一步行动和交付物。
- 周报：当前草稿、已提交、缺交、五周提交历史和强制生成的团队总结。
- 系统设置：用户权限、项目标签和审计记录。

AI 配置和真实 AI 对话不会写入伪造密钥；这两项需要在系统设置中接入可用模型后测试。
