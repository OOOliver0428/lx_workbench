# 协作工作台前端

现代化内网 MVP 前端，使用 React 19、Vinext 和 TypeScript。默认进入作战台，提供商机追踪、
工作管理与周期总览；项目、任务、工作记录、周报和系统设置作为事实录入与管理入口。

导航、作战台页签和写操作入口均根据登录响应中的有效权限动态展示。系统维护账号始终拥有
全部权限且不会出现在用户目录；新建账号默认可只读查看项目和任务，并可使用工作记录、
个人周报、AI 助手和个人设置。商机权限、团队工作管理、项目/任务编辑与创建需在“系统设置
→ 用户与权限”中按层级授权；高级权限会同步包含低级权限。系统级权限复选框对系统管理员
保持只读。

周报页面提供“我的周报”和按权限出现的“团队周报”页签。个人周报可按周目切换、编辑、
保存草稿和提交，但始终只读取本人内容；团队周报页签仅展示当前用户自己生成的历史汇总。
工作记录及作战台中的原始工作条目对非系统维护账号只展示本人数据。

## 本地启动

后端先运行在 `127.0.0.1:8787`，然后执行：

```powershell
Copy-Item .env.example .env.local
npm install
npm run dev
```

浏览器默认请求同源的 `/api`，由 Vinext 服务端转发到
`MVP_INTERNAL_API_BASE_URL`（默认 `http://127.0.0.1:8787`）。开发服务器固定使用
`http://127.0.0.1:5174`；修改后端地址时只需调整前端 `.env.local` 中的内部上游地址，
不应把后端端口直接暴露给浏览器。

## 验证

```powershell
npm run lint
npm test
```

`npm test` 会执行生产构建，并验证 SSR 页面、Session/CSRF 契约和 AI 密钥边界。
