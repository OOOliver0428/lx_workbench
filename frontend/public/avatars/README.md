# 系统头像资源约定

个人设置页不接受上传或外部图片地址，只读取本目录中的预置资源。此目录是构建产物目录，
原始图片默认保存在工程根目录的 `.static/` 中。原图属于本地设计源，不进入 Git；远程仓库
只保存本目录中经过统一处理的 WebP 生产资源。

- 生产格式：512 × 512 WebP
- 编码质量：86，清除原始图片元数据
- 安全构图：头像主体保持在中心 80% 区域，确保圆形裁切完整
- 风格：极简扁平、柔和黏土、简约像素、纸艺剪纸、手绘涂鸦、深色像素、立体黏土
- 文件名：`风格ID-01.webp` 至 `风格ID-08.webp`
- 完整资源清单：`catalog.json`

重新处理资源：

```powershell
npm run avatars:build
```

处理脚本会校验每套风格恰好包含 8 张至少 512px 的正方形 PNG；像素风采用最近邻缩放，
其他风格采用高质量 Lanczos 缩放。若原图位于其他目录，可通过 `AVATAR_SOURCE_DIR`
指定绝对路径或相对工程根目录的路径。
