# 解决方案部门周报

一个面向解决方案部门的轻量周报网页，按周次保存个人周报，并按项目汇总参与人员、交付物与投入工时。

## 功能

- 支持整段粘贴个人周报，自动拆分并识别项目。
- 支持逐项目填写工作事项、交付物和投入工时。
- 按项目查看每个人每周的交付物与工时。
- 使用本地 SQLite 保存所有周次数据，局域网内可共享访问。
- 每周日自动生成部门摘要，每周一自动生成数据库和 JSON 备份。
- JSON 数据可导出并重复导入，不会重复累加事项。

## 启动

macOS 可双击 `启动周报服务.command`，也可以在终端运行：

```bash
python3 server.py
```

浏览器打开：

```text
http://127.0.0.1:8787
```

同一局域网内的其他设备可访问启动日志中显示的局域网地址。详细说明见 [共享使用说明](./共享使用说明.md)。

## 测试

```bash
python3 -m unittest -v test_weekly_report_server.py
```

## 数据安全

运行时数据库、自动备份、导出文件和本地真实周报均已通过 `.gitignore` 排除，不会提交到代码仓库。
